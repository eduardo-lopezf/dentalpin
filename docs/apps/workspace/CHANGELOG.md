# Changelog — Espacio de trabajo (`workspace`)

The App's own version, which moves independently of its modules' (ADR 0036). Each module keeps its own `CHANGELOG.md`.

## 0.1

- Declared as the base App: no modules, always enabled (ADR 0043).
- Settings → Apps → Espacio de trabajo, with the home page layout (which widgets, in what order).
- 2026-10-04: the clinic picks the default theme (light, dark or the device's); each person keeps their own switch.
- 2026-10-04: the brand gains corners (sharp, soft, round) and density (comfortable, compact — with a mouse only).
- 2026-10-04: the brand gains an accent colour (eight) and a typeface (five, bundled with the app), per clinic, previewed on the canvas.
- 2026-10-04: the settings page is a canvas — a miniature of the app, edited in place — and the workspace has its own brand: the name and the logo the sidebar shows, in place of the product's.
